# Fotografías de categorías YALO

Las tarjetas usan imágenes locales optimizadas como WebP (480 × 480 px, calidad 78); la aplicación no consulta una CDN de imágenes durante su carga. El tratamiento navy/cian/menta, la textura y los títulos se aplican mediante CSS para mantener contraste y facilitar cambios.
